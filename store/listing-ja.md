# Chrome Web Store 掲載文（日本語）

## 名前
YouTube Shortcuts

## 短い説明（132文字以内）
YouTube 用のカスタムキーボードショートカット。再生・シーク・音量などを好きなキーに割り当て。

## 詳細な説明
YouTube Shortcuts は、YouTube の操作を好みのキーボードショートカットに割り当てられる Chrome 拡張機能です。

【できること】
• 再生 / 一時停止、シーク、音量、ミュート
• フルスクリーン、シアター、字幕
• 再生速度、前後の動画
• ツールバーからオン/オフ、オプションページでキー再割り当て

【使い方】
1. 拡張アイコンから有効化
2. 「キー割り当てを開く」で好きなキーを設定
3. インストール直後は YouTube タブを一度リロード

【注意】
同系統のショートカット拡張と同時に使うと競合します。1つだけ有効にしてください。
コメント欄や検索欄にフォーカスがあるときは無効です。Esc でフォーカスを外してから操作してください。

設定は Chrome の同期で他の PC にも反映されます（同じ Google アカウントで同期をオンにしてください）。

---

## 単一用途の説明（Single Purpose）

YouTube 上でキーボードショートカットをカスタマイズし、再生・シーク・音量などの操作をユーザーが割り当てたキーで実行できるようにする。

---

## 権限が必要な理由

### storage
ユーザーが設定したキー割り当てと、ショートカットの有効/無効を保存するためです。`chrome.storage.sync` を使い、同じ Google アカウントの Chrome 同期で他端末にも設定を渡します。閲覧履歴や個人データの収集・送信には使いません。

### ホスト権限（www.youtube.com / m.youtube.com）
YouTube のページ上でのみキーボード入力を受け取り、プレイヤー操作（再生・シーク・音量など）を行うためです。コンテンツスクリプトを YouTube に限定して注入し、他サイトでは動作しません。ページ内容の収集や外部送信は行いません。
